## Denormalisation break-even

The measured cost of rebuilding the wide table against the measured per-query saving — the arithmetic the advice never includes.

```
per-query saving         47,632 slot-ms       156.0 MiB billed
one rebuild costs       425,009 slot-ms      2179.0 MiB billed   (median of 5)

break-even, slot time     8.9 queries per rebuild
break-even, on-demand    14.0 queries per rebuild

wide table           2.152 GiB
3 normalised         2.127 GiB   -> denormalising costs +1.2% storage
extra storage      $  0.043/month
nightly rebuild    $  0.390/month   (9x the storage)
```

Columnar compression absorbs nearly all the duplication, so the storage warning attached to this advice is close to noise. The binding constraint is refresh frequency: below roughly 9–14 queries per rebuild cycle you spend more refreshing the table than you save reading it.
